Entry for make.fun's "Bring the most entrants to the bounties you make on make.fun": three sponsored one-line comedy bounties — The Worst Superpower, The One-Line Excuse, and Sarcastic Fortune Cookie — handed in as BOUNTY.json. The house counts their entrants in its own database; the most entrants wins a share of $1,000.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
